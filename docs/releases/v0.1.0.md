# Sensor-Log-Studio v0.1.0 — draft

Initial MIT-licensed offline browser prototype. Open `index.html` directly; runtime requires no Node.js, server, or npm installation. Node.js/Playwright are development-test dependencies only.

## Acceptance gate

- `npm ci`, `npm test`, and `npm run test:browser` must pass.
- Tests assert real browser imports, user actions, downloaded data and relevant storage/error behavior.
- Independent spec and quality review must be resolved before publication.
- Only fictional examples and fixtures are shipped; no private car logs or personal records.

## Platform evidence

Local verification is Chrome on Windows ARM64. Linux Chromium checks are configured in CI but not claimed as run until the exact published head passes. x86/x64 hardware has not been independently tested.

This is a prototype, not vehicle control, a repair certification, or a safety assessment. Known format and storage limitations are in README.md. This file is a release draft, not a published GitHub Release.
